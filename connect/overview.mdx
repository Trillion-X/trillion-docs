Trillion works inside the AI you already use. You add it once to each AI app, sign in, and that AI gets Trillion's tools. Every AI you connect reaches the same Trillion, so what you start in one, another can pick up.

## Easiest: let your AI set it up

Copy the message below and paste it into the AI you use. If it can run terminal commands, it sets Trillion up itself. Otherwise it walks you through each click, one step at a time.

```text Setup message
Help me connect Trillion to the AI app I use, so you (or that app) can use Trillion's tools. Set up only the AI app I am using or explicitly choose. If that AI cannot connect, or the required sign-in or connector is unavailable, stop at that exact boundary and tell me what is missing; never choose the first installed or shipped AI, CLI, model, or another app as a fallback. Trillion is an MCP server at this address: https://app.gettrillion.ai/mcp
It signs in with OAuth: I sign in on a Trillion page with my passkey, my password or an emailed code, never an API key. When I use Chrome or another Chromium browser, also offer the official Send to Trillion extension from the Chrome Web Store so I can send pages, selections, pictures and files to this Trillion. If the extension is not listed there yet, say that plainly and do not tell me to install an untrusted copy or load an unpacked folder.

Please do this:
1. If you can run terminal commands yourself, do the setup for me instead of explaining it:
   - If you are Claude Code, run: claude mcp add --transport http --scope user trillion https://app.gettrillion.ai/mcp
     Then ask me to type /mcp, choose trillion and choose Authenticate (or run claude mcp login trillion in my own terminal), and I will sign in.
   - If you are Codex, run: codex mcp add trillion --url https://app.gettrillion.ai/mcp
     It opens my browser to sign in; I will sign in.
   Afterwards run claude mcp list or codex mcp list and show me that trillion is there.
   Then let Trillion's tools run without asking me each time: in Claude Code add "mcp__trillion" to permissions.allow in ~/.claude/settings.json; in Codex add default_tools_approval_mode = "approve" under [mcp_servers.trillion] in ~/.codex/config.toml.
2. Otherwise, ask me which app I want to connect (claude.ai or the Claude desktop app, ChatGPT, Muse, Cursor, or another one), then walk me through it ONE step at a time. For each step tell me the exact menu or button to click, what to type or paste, and what to leave alone. Wait for me to say done before giving the next step. Then tell me what I should see if it worked.
   - claude.ai or the Claude desktop app: left sidebar, Customize, Connectors, the + button, Add custom connector. Name: Trillion. URL: https://app.gettrillion.ai/mcp. Leave "Sign in now", "Use Claude's published identity" and "Streamable HTTP" as they are and click Add. Then click Connect next to Trillion and tap the passkey. Then click Trillion and, under Tool permissions, choose Always allow for each group of tools. In a chat: the + at the bottom left, Connectors, switch Trillion on. Each claude.ai account has its own connectors, so a second account adds Trillion once and signs in with the same passkey.
   - ChatGPT (in a web browser): Settings, Security and login, switch on Developer mode. Then chatgpt.com/plugins, the + button. Name: Trillion. Connection: Server URL, https://app.gettrillion.ai/mcp. Authentication: leave OAuth. Tick "I understand and want to continue", click Create, tap the passkey. In a chat: the +, Developer mode, Trillion.
   - Cursor: Cursor Settings, MCP section, add a new MCP server, and put this in mcp.json: {"mcpServers": {"trillion": {"url": "https://app.gettrillion.ai/mcp"}}}. Save, click Connect next to trillion, tap the passkey.
   - Muse (Meta's AI) or another AI that connects when asked in a chat: if that is you, connect yourself with your own "Add a custom connector" sheet using OAuth, with these values: authorization_url https://app.gettrillion.ai/authorize; token_url https://app.gettrillion.ai/oauth/token; client_id muse (for Meta's redirect https://agent.meta.ai/api/hatch/oauth/callback; any other redirect registers itself at https://app.gettrillion.ai/oauth/register with no secret); token_endpoint_auth_method none; scope decisions. Then send me the Add a custom connector link, and tell me to tap Connect and then my passkey inside the sheet. Never send me a 127.0.0.1 link, never ask me to copy an address back to you, and never ask me for a client id, secret or key.
   - Another app: find where it adds an MCP server or connector, paste https://app.gettrillion.ai/mcp, and choose OAuth if it asks how to sign in.
3. If what I see on my screen does not match your step, ask me to describe the screen and adjust. Never ask me for a password, an API key or a client id.
4. When it is connected, list Trillion's tools to show it works, then ask me what I want to do first.
```

## One account, many apps

- **Each app adds Trillion once.** Claude, ChatGPT, Cursor and the others each keep their own list of connectors, so you add Trillion in each app you use.
- **Terminal apps add it once per computer.** Claude Code, Codex and Cursor keep their list on each computer, so you add Trillion once on each computer you use them on.
- **Every app reaches the same Trillion.** Sign in to the same account and every app reads and writes the same decisions, files and goals.

A paid plan keeps every decision, note and result, and adds running tools from the Marketplace, your files, shared spaces, the network and handing work between your AI apps.
