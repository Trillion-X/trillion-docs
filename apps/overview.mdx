Trillion is one account you reach from wherever you are: the apps below for your devices, the web at app.gettrillion.ai, and any AI app you already use. Everything you send from one place is there in all the others.

## Apps for your devices

<CardGroup cols={2}>
<Card title="Trillion on your iPhone">
  Add photos, videos, links and notes to Trillion from any app's Share button.

  - [Get it on TestFlight](https://testflight.apple.com/join/6pNXRtSD)
  - [How it works](/apps/iphone)
</Card>
<Card title="Send to Trillion for Chrome">
  Send any page, selection or screenshot from your browser to Trillion. Works in Chrome, Arc, Dia, Edge and Brave.

  - [Add to Chrome](https://chromewebstore.google.com/detail/send-to-trillion/hlcppfhpcfmlinjmjkiadmbnnboadlnh) for a Mac, Windows or Linux
  - [How it works](/apps/chrome-extension)
</Card>

  - [Download for Mac](https://app.gettrillion.ai/download/Trillion.dmg) for a Mac
  - Download for Windows: Not out yet for Windows.
  - Download for Linux: Not out yet for Linux.

## From the AI you already use

Connect your AI once and it can use Trillion in every chat. Each card says how.

<CardGroup cols={2}>
<Card title="Grok" href="https://app.gettrillion.ai/ai">
  Connect Trillion to Grok with a custom connector. Grok Business and Enterprise accounts need an admin to add it first.
</Card>
<Card title="Claude" href="/connect/claude-desktop">
  For claude.ai and the Claude desktop app, on any plan (the Free plan allows one custom connector). Each claude.ai account keeps its own list of connectors, so a second Claude account adds Trillion once too and signs in with the same passkey, reaching the same Trillion. Claude Code keeps its own list on each computer instead (see the Claude Code tab).
</Card>
<Card title="ChatGPT" href="/connect/chatgpt">
  For ChatGPT in a web browser at chatgpt.com, on the Plus, Pro, Business, Enterprise and Education plans. Set it up in the browser; the phone app cannot add it.
</Card>
<Card title="Muse and other AIs you connect in chat" href="/connect/muse">
  For Muse (Meta's AI) and any AI that has no settings screen for this: you connect it by sending it a message. It runs on its own computer in the cloud, so it only ever uses Trillion's web address. Do this once for each account you use it with.
</Card>
<Card title="Claude Code" href="/connect/claude-code">
  For Claude Code in your terminal. Claude Code keeps its own list on each computer, separate from your claude.ai account: do this once on each computer you use, and it covers every Claude account you use there, including several accounts a local proxy such as CLIProxyAPI switches between.
</Card>
<Card title="Codex" href="/connect/codex">
  For Codex in an editor, the Codex app or Terminal. They read the same server list on this computer, so add Trillion once per computer.
</Card>
<Card title="Gemini" href="https://app.gettrillion.ai/ai">
  For the Gemini app at gemini.google.com, with a personal Google Account, for people 18 or over in the US, in English. Add it in the web app; it then works in the Gemini phone app too. Work and school Google Accounts cannot add it.
</Card>
<Card title="Gemini CLI" href="/connect/gemini-cli">
  For Gemini in your terminal (the Gemini CLI). For the Gemini app in a browser, use the Gemini tile.
</Card>
<Card title="Cursor" href="/connect/cursor">
  For the Cursor editor. Do it once on each computer you use.
</Card>
<Card title="Any other AI app" href="/connect/other-apps">
  Any app that can add an MCP server or a connector.
</Card>
</CardGroup>
