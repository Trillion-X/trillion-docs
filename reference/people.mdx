The Trillion network finds people by what they offer and what they are looking for. Contact details are shared only when both people agree to meet. Trillion's network comes with a paid plan.

You do not call these tools yourself. You ask your AI in plain words, and it picks the tool. This page shows what each one does, so you know what to ask for.

## Set how people can find me

`network_profile` · Changes things

Changes this person's Network profile. When Network is available, setup fills known basics once; send only fields they want to change. A findable profile appears to other people. Contact is released only after both people agree to meet and while both stay connected. A handle is unique and can be changed. Connected AIs, counts and pursuits each stay hidden until turned on.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `findable` | boolean |  |  |
| `name` | string |  |  |
| `handle` | string |  |  |
| `about` | string |  |  |
| `offering` | string |  |  |
| `seeking` | string |  |  |
| `links` | string[] |  |  |
| `open_to_messages` | boolean |  |  |
| `show_ais` | boolean |  |  |
| `show_counts` | boolean |  |  |
| `show_pursuits` | boolean |  |  |
| `contact` | string |  | Email, phone or handle; released only after an accepted introduction |

```json Example
{
  "findable": true,
  "offering": "Brand design for small software companies",
  "seeking": "A part-time bookkeeper",
  "contact": "you@example.com"
}
```

## Find people

`find_people` · Reads only

Finds people in the network by meaning: what they offer and seek, how close the match is, and what asking to meet them costs from today's credits (people who share a group or introduction with this person cost less). Returns relay ids, never contact details.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `need` | string | Yes |  |

```json Example
{
  "need": "Someone who can help with brand design"
}
```

## Ask to meet someone

`request_introduction` · Changes things

Asks to meet a person found with `find_people`, or invites them into a group, project or event this person belongs to (membership_id); a group or project is a space its members work in together (`list_spaces`). The reply is always "sent": a person who ignores or declines it looks the same as one who does not exist. Contact details are shared only if they accept.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `to` | string | Yes | A relay id from `find_people` |
| `why` | string | Yes |  |
| `membership_id` | string |  |  |

```json Example
{
  "to": "<relay id from find_people>",
  "why": "I am redoing my brand and liked your work for small software companies."
}
```

## My network

`network` · Reads only

This person's network: requests waiting for their answer, what they asked, and every one-to-one, group or event they belong to with each other member's contact, read live and only while both still belong.

It takes no inputs.


## Answer a request to meet

`answer_introduction` · Changes things

Accepts or declines a request waiting for this person (from the network tool). Accepting connects both people and shares each one's contact with the other; accepting an invitation into a group or project also joins its space, which holds only what members put there, never anyone's private Trillion. Declining is never told to the asker.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `request_id` | string | Yes |  |
| `accept` | boolean | Yes |  |

```json Example
{
  "request_id": "<request_id>",
  "accept": true
}
```

## Label a person

`label_person` · Changes things

Gives a person in the network a label: unwanted-requests, unsafe or vouched. Enough people, or anyone this person is connected to, labelling someone unwanted-requests or unsafe hides them from this person's searches.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `relay` | string | Yes |  |
| `label` | string | Yes |  |

```json Example
{
  "relay": "<relay>",
  "label": "<label>"
}
```

## My referral link and who joined

`my_referrals` · Reads only

Reads this person's own referral link and who joined with it: links (the addresses to share; the first is the one to give out), friend_gets (what someone who joins with the link gets off their first payment of the paid plan: kind amount with amount_cents and currency, or kind percent with percent), you_get (amount_cents and currency: credit taken off their bill for each of those people the first time they pay, with no limit unless at_most_per_year names one), counts (joined, paying, credit_given_cents, waiting: a credit waits until this person pays for a plan themselves) and people (each person's account name, when they joined, when they first paid and what it earned). Use it to share their link (with someone pursuing something worthwhile for the greater good of human society who needs better decisions) or tell them what they earned. It changes nothing.

It takes no inputs.

```json Example
{}
```

## Offer or change a stay

`save_stay` · Changes things

Offers a place to stay because of the person hosting it. A city or area is shown, never a street address. A stay appears to others only while your Network profile is findable. A nightly price is a quoted offer; payment is arranged in Trillion only after you accept a guest.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `stay_id` | string |  | The stay to change; leave out to create one |
| `title` | string | Yes |  |
| `where` | string | Yes | City or area, not a street address |
| `about` | string |  |  |
| `when` | string |  |  |
| `price` | object | Yes |  |
| `price.kind` | string | Yes | One of `free`, `per-night`, `ask`. |
| `price.amount_cents` | integer |  |  |
| `price.currency` | string |  |  |
| `active` | boolean |  |  |

```json Example
{
  "title": "<title>",
  "where": "<where>",
  "price": {
    "kind": "free"
  }
}
```

## Ask to stay

`request_stay` · Changes things

Asks a host about specific dates. This uses the Network introduction credits. The host may accept to open a private stay space. A paid stay remains unpaid until Trillion confirms payment; sending a request never charges the nightly price.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `stay_id` | string | Yes |  |
| `start_date` | string | Yes |  |
| `end_date` | string | Yes |  |
| `note` | string | Yes |  |

```json Example
{
  "stay_id": "<stay_id>",
  "start_date": "<start_date>",
  "end_date": "<end_date>",
  "note": "<note>"
}
```
