title: "Public apps and source projects"
description: "Publish small public apps with visitor actions, connect domains, and edit a connected GitHub project's source."
---

These tools publish a public app (its pages and the actions visitors can take), install it in the account or a space, connect a domain, read responses and visits, and change a connected GitHub project's source at an exact revision.

You do not call these tools yourself. You ask your AI in plain words, and it picks the tool. This page shows what each one does, so you know what to ask for.

## Publish a public app

`publish_public_app_definition` · Changes things

Publish the files and declared visitor actions for a reusable public app. Check that words, assets and any promised action are ready to share before publishing. Returns the version to install.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `id` | string | Yes |  |
| `files` | object | Yes | File paths mapped to their UTF-8 contents; include index.html. |
| `actions` | object[] | Yes |  |
| `actions[].id` | string | Yes |  |
| `actions[].record_kind` | string | Yes |  |
| `actions[].fields` | object[] | Yes |  |
| `actions[].fields[].id` | string | Yes |  |
| `actions[].fields[].type` | string | Yes | One of `text`, `email`, `number`, `boolean`, `date`. |
| `actions[].fields[].required` | boolean |  |  |

```json Example
{
  "id": "<id>",
  "files": {
    "index.html": "<index.html>"
  },
  "actions": [
    {
      "id": "<id>",
      "record_kind": "<record_kind>",
      "fields": [
        {
          "id": "<id>",
          "type": "text"
        }
      ]
    }
  ]
}
```

## Edit a public app draft

`edit_public_app_draft` · Changes things

Save exact text replacements in an installed public app HTML or CSS file. The draft does not change the live page until `publish_public_app_draft` runs.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `installation_id` | string | Yes | The public app installation id. |
| `expected_revision` | string | Yes | The current revision returned by `read_public_app_installation`. |
| `commands` | object[] | Yes |  |
| `commands[].type` | string | Yes |  |
| `commands[].path` | string | Yes |  |
| `commands[].find` | string | Yes |  |
| `commands[].replace` | string | Yes |  |

```json Example
{
  "installation_id": "<installation_id>",
  "expected_revision": "<expected_revision>",

    {
      "type": "<type>",
      "path": "<path>",
      "find": "<find>",
      "replace": "<replace>"
    }
```

**Inputs**

| --- | --- | --- | --- |
| `project_id` | string | Yes |  |
| `expected_commit` | string | Yes |  |
| `selection` | object | Yes |  |

```json Example
{
  "project_id": "<project_id>",
  "expected_commit": "<expected_commit>",
  "selection": {}
}
```

## Edit original source

`edit_source_project` · Changes things

Apply one supported visual edit to the verified original source file at its exact revision: literal text, an existing inline style value, or an existing safe link, local image path, or class value. Attribute edits never add new attributes or executable values. Returns the committed source and verification state; a build or live deployment is never inferred from the commit.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `project_id` | string | Yes |  |
| `expected_commit` | string | Yes |  |
| `selection` | object | Yes |  |
| `locator` | object | Yes |  |
| `intent` | object | Yes |  |

```json Example
{
  "project_id": "<project_id>",
  "expected_commit": "<expected_commit>",
  "selection": {},
  "locator": {},
  "intent": {}
}
```
