Your content formats say how you write each kind of piece, from a newsletter to a short video. The audience question tools keep questions people ask in public, check them against their sources, and keep a private draft answer. Nothing here is published.

You do not call these tools yourself. You ask your AI in plain words, and it picks the tool. This page shows what each one does, so you know what to ask for.

## Read my content formats

`content_formats` · Reads only

The content formats this person writes and speaks in: their own saved formats first, then the ones every account starts with (blog post, article, Substack post, newsletter, X thread, Instagram caption, short video, YouTube video, carousel, content series, and writing frameworks such as AIDA), plus example_kinds, where every piece takes its real examples from. Each has id, label, description, input (what it is made from), process (the steps, in order), output (what comes out and where it goes), spec (how to write it from a recording or a thought), slots (its parts in order, each &#123; id, label, hint &#125;), body_template (the parts in [brackets], when it has one), tags and from ("saved" or "starter"). Read it before writing something for them, and write in their format. It changes nothing.

It takes no inputs.

```json Example
{}
```

## Save my content formats

`save_content_formats` · Changes things

Replaces this person's own content formats (read `content_formats` first, then send the whole list with your change). Each format: label, and spec (how it goes, in words) or slots (its parts in order, each &#123; label, hint &#125;), optionally id, description, content_type (such as text/markdown), input, process (its steps in order) and output (what comes out and where it goes), body_template (the parts in [brackets]) and tags. Use it to keep a format they studied from a post they shared or one they describe. A format with a starter's id replaces that starter for them. Returns what `content_formats` returns.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `formats` | object[] | Yes |  |
| `formats[].id` | string |  |  |
| `formats[].label` | string | Yes |  |
| `formats[].description` | string |  |  |
| `formats[].content_type` | string |  |  |
| `formats[].input` | string |  |  |
| `formats[].process` | string[] |  |  |
| `formats[].output` | string |  |  |
| `formats[].spec` | string |  |  |
| `formats[].slots` | object[] |  |  |
| `formats[].slots[].id` | string |  |  |
| `formats[].slots[].label` | string | Yes |  |
| `formats[].slots[].hint` | string |  |  |
| `formats[].body_template` | string |  |  |
| `formats[].tags` | string[] |  |  |

```json Example
{
  "formats": [
    {
      "label": "Weekly note",
      "spec": "A hook line, one story from the week, one lesson, one question for readers."
    }
  ]
}
```

| Input | Type | Required | What it is |

## Shape a thought into my formats

`shape_into_formats` · Reads only

Drops one thought into each of this person's content formats (or only the format_ids named, in that order) and returns each as a script to say or write: its parts in order, the first carrying the thought and every later part what to say next in the format's own words, plus the whole script as text and the format's input, steps and output. The same scripts the Formats screen shows. Use it to show someone how one idea reads as a post, a thread, a video and the rest, then write the one they pick. It changes nothing.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `thought` | string | Yes | What they want to talk about, in their words |
| `format_ids` | string[] |  | Only these formats (ids from `content_formats`); every format when left out |

```json Example
{
  "thought": "<thought>"
}
```

## Follow my script

`follow_script` · Reads only

Finds how far someone has read through a format's script from the words heard (a live transcript or a finished one), the way the Record screen's teleprompter follows a voice: each word heard is looked for a few words ahead of the place reached, so an aside or a misheard word never loses the place and it never moves back. Give format_id and about (the thought the script was made with) as `shape_into_formats` took them, heard, and said (the place from an earlier call) to continue. Returns said (script words read), total, progress (0 to 1), done, and next_words, what comes next. It changes nothing.

**Inputs**

| Input | Type | Required | What it is |
| --- | --- | --- | --- |
| `format_id` | string | Yes |  |
| `about` | string |  |  |
| `heard` | string | Yes | The words heard since said |
| `said` | integer |  | The place already reached (said from an earlier call); 0 when left out |

```json Example
{
  "format_id": "<format_id>",
  "heard": "<heard>"
}
```
